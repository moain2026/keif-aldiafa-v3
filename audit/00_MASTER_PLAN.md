## 🗺️ خارطة التنفيذ (5 مراحل مرتبة بالأثر)

### 🔴 المرحلة 1 — إصلاحات حرجة سريعة (نفس اليوم)
1. تصحيح "صباح قهوة" → "صبابين قهوة" (4 مواضع في services/page.tsx) — يظهر في نتائج البحث الآن.
2. إدخال "قهوجيين/قهوجية" في H1s والنصوص المرئية (الرئيسية + الخدمات + عن).
3. H1 غنية بالكلمات لكل صفحة (مع إبقاء الجملة الشاعرية كسطر `<p>` تحتها).
4. Titles داخلية غنية (services/offerings/portfolio/contact).
5. إصلاحات تقنية سريعة: href="/services"، h2 مكررة، microdata breadcrumb مزدوج.

### 🔴 المرحلة 2 — الأداء و Core Web Vitals
1. **CLS /services 1.405→<0.05:** aspect-ratio ثابت لكل صورة بطاقة + motion بـ transform فقط.
2. **LCP 5.6→~2.3s:** priority+fetchPriority للـ hero، preload في head، الفيديو preload="none".
3. تقليل أوزان الخطوط (4 أوزان بدل 6-7 لكل خط).
4. dynamic import لـ motion/embla، optimizePackageImports.
5. blur placeholders للصور الكبيرة.

### 🟠 المرحلة 3 — صفحات المدن (أعلى أثر على الترتيب) ⭐ طلب العميل
**البنية:**
```
src/app/locations/
├── page.tsx              # فهرس "خدماتنا في مدن المملكة" (شبكة البطاقات الفاخرة كالصور)
└── [slug]/page.tsx       # SSG لكل (خدمة × مدينة)
src/lib/locations-data.ts # مصدر البيانات الوحيد
```
**الصفحات المطلوبة (خدمة × مدينة):**
- صبابين قهوة: جدة، مكة، المدينة، ينبع، بدر، الرياض، الدمام
- قهوجي / قهوجيين: جدة (+ باقي المدن)
- مباشرين قهوة: جدة (+ مدن)
- صبابين سعوديين: جدة
- ضيافة مناسبات: جدة، مكة، المدينة، ينبع، بدر (+ مدن)
- صبابات/مباشرات (السوق النسائي): جدة + مدن

**التصميم:** شبكة بطاقات ذهبية/سوداء فاخرة (عمودين، border ذهبي، عنوان الخدمة + "في {المدينة}") — مطابقة للصور المرفقة وموقع أصول الضيافة، بنفس ألوان الموقع (#B8860B / #0f0f0f).

**قواعد تجنّب عقوبة doorway (حرجة):**
- محتوى فريد 400-700 كلمة لكل صفحة (أحياء، قاعات/فنادق المدينة، صور مناسبات فعلية فيها).
- Schema: `Service` (areaServed=City) + `BreadcrumbList` + `FAQPage` — **لا** LocalBusiness مكرر.
- FAQ خاص بكل مدينة (سعر، حجز، تغطية) — مرئي + schema.
- صور مناسبة مستنسخة/مصنّفة من الـ388 صورة الحالية.
- ربط من الفوتر + فهرس المدن + الرئيسية.

### 🟠 المرحلة 4 — المحتوى و E-E-A-T و Schema
1. قسم FAQ مرئي (accordion) على الرئيسية يطابق FAQPage schema (مخالفة حالياً).
2. قسم نصي "خدمات الضيافة في مدن المملكة" على الرئيسية (150-250 كلمة + روابط المدن).
3. تعميق /about: سجل تجاري، فريق، أرقام موثقة، شعارات عملاء.
4. Schema: نوع `Caterer`، hasOfferCatalog، sameAs (tiktok)، Service لكل خدمة.
5. قسم "آراء عملائنا" مرئي + AggregateRating/Review (بأرقام حقيقية فقط — بعد جمع تقييمات).
6. ربط داخلي سياقي بين الصفحات بنصوص وصفية.

### 🟠 المرحلة 5 — الأمن والجودة والمراقبة
1. تشديد CSP (إزالة unsafe-eval في الإنتاج، إضافة object-src/frame-src 'none', COOP/CORP).
2. حذف remotePatterns غير المستخدمة (unsplash/placeholder) — يغلق ثغرة Image DoS.
3. `rel="noopener"` للروابط الناقصة (HomePageClient:188)، X-XSS-Protection→0، Referrer-Policy تشديد.
4. lighthouse-ci بعتبات (perf≥90, seo≥95, a11y=100) لمنع الانحدار.
5. تقييم ترقية Next 15 (Next 14 انتهى أمنياً) — مرحلة لاحقة منفصلة (تتطلب اختباراً دقيقاً).
