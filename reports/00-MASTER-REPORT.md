## 🔴 المشكلة #1: الفهرسة (9/47)

**الدليل (صورة GSC 2026/7/10):** مفهرسة=9، غير مفهرسة=38 لثلاثة أسباب:
- **"Discovered – not indexed" = 22 صفحة** (about, contact, كل diyafa-munasabat-*) — Google يعرفها لكن لم يفهرسها.
- **"Page with redirect"** = روابط `?page_id=` القديمة (301 صحيح، طبيعي).
- **"noindex"** = صفحة واحدة مستثناة.

**السبب المؤكّد (تحليل الكود):** `src/lib/localContent.tsx` — 24 صفحة (3 خدمات × 8 مدن) تتشارك:
- sections/packages/faqs **متطابقة 100%** عدا استبدال اسم المدينة.
- التمايز الفعلي = اسم المدينة + جملة واحدة + قائمة أحياء.

**الإصلاح:**
1. **تفريد محتوى كل مدينة** (نص فريد حقيقي: أحياء، معالم، نوع المناسبات المحلية، أمثلة).
2. تقوية **الربط الداخلي** (Hub & Spoke: الرئيسية/locations → صفحات المدن).
3. ضمان lastmod حديث في sitemap + **طلب فهرسة** بعد التحسين.
4. فحص صفحة الـnoindex وإزالتها إن كانت مهمة.

## 🔴 المشكلة #3: الأداء على الجوال (73) — LCP = 9.1s!

**الدليل (تقرير Manus AI + PageSpeed 2026/7/22):**
| المقياس | القيمة | التقييم |
|---------|:---:|---------|
| FCP | 0.9s | 🟢 ممتاز |
| **LCP** | **9.1s** | 🔴 ضعيف جداً (المطلوب <2.5s) — القاتل الرئيسي |
| TBT | 130ms | 🟢 جيد |
| CLS | 0 | 🟢 مثالي |

**السبب المؤكّد:** صورة الهيرو `hero-desktop.webp` تتأخّر 9.1s لأن CSS يحظر عرضها. + قسم الشركاء 45 صورة تُحمّل دفعة. + 142KB JS غير مستخدم + أكواد تتبع (GA/Ads) تعطّل.

**الإصلاح (مرتّب):**
1. `priority` + `fetchPriority=high` + preload لصورة الهيرو (الأهم).
2. قسم الشركاء: lazy/تقليل الصور الفورية (45→أقل).
3. تأجيل أكواد التتبع (GA/Ads) حتى تفاعل المستخدم.
4. dynamic import للـ142KB JS غير المستخدم.
5. responsive sizes + ضغط الصور الكبيرة (35MB، أكبرها 1.1MB).

**ملاحظة:** تقرير Manus ذكر "نقص CSP" — لكن الفحص الحي يؤكّد وجود CSP كامل في next.config.js (Manus فحص نسخة قديمة على الأرجح).
