# TITLES-COPY.md — نسخ تسويقي نهائي للعناوين والأوصاف (CTR Fix)

**الهدف:** رفع CTR من 0.4–1.1% إلى 4%+ على صفحات المال (24 صفحة خدمة×مدينة + 8 صفحات مدن).
**المرجع:** `reports/DEEP-ANALYSIS-SEO.md` §1.1 — هذه النسخة تطوير نهائي مدقّق الأحرف للصيغ المقترحة هناك.

---

## قواعد الصياغة المطبّقة هنا

1. **القالب يضيف `| كيف الضيافة` (14 حرفاً) تلقائياً** (`layout.tsx:32`) — لا براند في العناوين أدناه.
2. **≤ 50 حرفاً عربياً قبل البراند** حتى مع أطول مدينة («المدينة المنورة» = 15 حرفاً) → لا بتر للجزء التسويقي أبداً؛ إن قُصّ شيء فهو ذيل البراند فقط.
3. **خطّاف نقر واحد قوي لكل خدمة** (لا حشو مرادفات في الـ title — المرادفات موجودة في المحتوى وschema):
   - صبابين قهوة (ترتيب 3.8): **تميّز + فورية** → «طاقم سعودي وحجز فوري».
   - قهوجيين (742 ظهور × 0.4%): **فورية** → «حجز فوري وزيّ رسمي VIP» (نية البحث عاجلة: أغلب الحجوزات قبل المناسبة بأيام).
   - ضيافة مناسبات: **نطاق + بروتوكول** → «أعراس ومؤتمرات VIP».
   - صفحة المدينة (hub): **إثبات اجتماعي** → «خبرة +500 مناسبة» — **بدون** قهوجيين/صبابين في الـ title (منع cannibalization مع صفحات الخدمة، راجع §1.2).
4. **الوصف: القيمة في أول 60 حرفاً** (الجزء المضمون على الجوال) = ✓ رموز + إثبات (+500 مناسبة) + تمييز (طاقم سعودي)، ثم الكلمة المفتاحية طبيعياً، ثم CTA واتساب `0508252134` في النهاية (نقرة شبه-تحويل حتى بلا زيارة). كله **≤ 155 حرفاً** مع أطول مدينة.

## 1) الكود الجاهز — `src/lib/localContent.tsx` (بدل كتلة metaTitle/metaDescription الحالية ~الأسطر 70–80)

```tsx
  // عناوين ≤50 حرفاً قبل البراند (تنجو من البتر حتى مع «المدينة المنورة») + خطّاف نقر واحد قوي.
  // القالب يضيف «| كيف الضيافة» تلقائياً — لا نكرره هنا. المرادفات مكانها المحتوى لا الـ title.
  const metaTitle = isMunasabat
    ? `ضيافة مناسبات ${c.ar} — أعراس ومؤتمرات VIP`
    : isQahwajiin
    ? `قهوجيين ${c.ar} — حجز فوري وزيّ رسمي VIP`
    : `صبابين قهوة ${c.ar} — طاقم سعودي وحجز فوري`;

  // الوصف: القيمة أولاً (أول 60 حرفاً هي الأهم) + ✓ رموز + إثبات اجتماعي + CTA واتساب. ≤155 حرفاً.
  const metaDescription = isMunasabat
    ? `✓ تجهيز كامل بمعدات فاخرة ✓ خبرة +500 مناسبة ✓ طاقم سعودي. ضيافة أعراس ومؤتمرات في ${c.ar} ببروتوكول VIP. عرض سعر مجاني — واتساب ${WA_DISPLAY}`
    : isQahwajiin
    ? `✓ حجز خلال دقائق ✓ خبرة +500 مناسبة ✓ زيّ رسمي موحّد. قهوجيين ومباشرين سعوديون لخدمة كبار الضيوف في ${c.ar}. اطلب عرض سعرك — واتساب ${WA_DISPLAY}`
    : `✓ طاقم سعودي بزيّ تراثي ✓ خبرة +500 مناسبة ✓ صبابات للنسائية. قهوة عربية ودلال وتمر ضمن الخدمة في ${c.ar}. اطلب عرض سعرك الآن — واتساب ${WA_DISPLAY}`;
```

### h1 — الحالي جيد (كلمة مفتاحية + تمايز واضح بين الخدمات). لا تغيير إلزامياً.
اختياري إن أردت مواءمة الخطّاف مع العنوان (لا تنسخه حرفياً — h1 ≠ title):

```tsx
  const h1 = isMunasabat
    ? `ضيافة مناسبات في ${c.ar} — تجهيز أعراس ومؤتمرات وفعاليات`
    : isQahwajiin
    ? `قهوجيين ومباشرين سعوديون في ${c.ar} لخدمة كبار الضيوف`
    : `صبابين قهوة سعوديون في ${c.ar} — تقديم القهوة العربية على الأصول`;
```
(أي: **أبقِ h1 كما هو** — يحمل المرادفات «ومباشرين/سعوديون» التي أزلناها من الـ title عمداً.)

## 2) الكود الجاهز — `src/app/locations/[city]/page.tsx` (بدل الأسطر ~34–39 داخل generateMetadata)

```tsx
  return generatePageMetadata({
    // hub المدينة بدون «قهوجيين/صبابين» في الـ title — صفحات الخدمة تستهدفها (منع تنافس داخلي).
    title: `ضيافة فاخرة في ${city.name} — خبرة +500 مناسبة`,
    description: `✓ خبرة +500 مناسبة ✓ طاقم سعودي محترف ✓ تغطية كل أحياء ${city.name}. قهوجيين وصبابين قهوة وتجهيز ضيافة متكامل. عرض سعر مجاني — واتساب 0508252134`,
    path: `/locations/${city.slug}`,
    keywords: city.keywords,
  });
```

> ملاحظة: هذا الملف لا يستورد `WA_DISPLAY`؛ الرقم مضمّن نصياً (نفس رقم `WHATSAPP` المعرّف أعلاه في الملف). إن أردت مصدراً واحداً أضف `const WA_DISPLAY = "0508252134";` بجانب `const WHATSAPP`.

اختياري — h1 صفحة المدينة (إن لم يكن كذلك): `خدمات ضيافة فاخرة في ${city.name}` (يُبقي الكلمات الخدمية في h2/المحتوى).
