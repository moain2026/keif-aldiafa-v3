> المرجع: PLAN.md §0 و §2 — تكليف المالك (المواد 6، 8، 12).
> لا يُعتمد أي عمل دورة إلا بعد اجتياز هذه البوابة بالأدلة.

## قائمة الفحص الإلزامية لكل دورة (قبل اعتماد أي دمج/تسليم)

| # | الفحص | الأمر | معيار النجاح |
|---|-------|-------|--------------|
| 1 | أخطاء TypeScript | `npx tsc --noEmit` | صفر أخطاء |
| 2 | البناء الإنتاجي | `npm run build` | نجاح نظيف بلا تحذيرات |
| 3 | Lint | `npm run lint` | صفر أخطاء (التحذيرات تُسجَّل وتُصفَّر تدريجياً) |
| 4 | Lighthouse موبايل (بناء إنتاجي) | lighthouse ضد `next start` | Perf ≥85 · LCP ≤2.5s · TBT ≤300ms · CLS ≤0.1 · A11y = 100 |
| 5 | زحف المسارات | فحص كل صفحة/رابط/أصل | صفر مسارات مكسورة |
| 6 | مراجعة diff يدوية | `git diff <prev>..<head>` | لا مخاطر أمنية/منطقية، الالتزام بقيود المادة 10 |
| 7 | الأدلة | ملفات في docs/evidence/ | كل رقم له مخرجات أمر محفوظة |

## قواعد ثابتة
- كل القياسات على **بناء إنتاجي** (`next build` + `next start`) — القياس على dev مرفوض ويُعاد (المادة 9).
- ممنوع الدفع إلى main (المادة 2). كل الشغل على `feat/homepage-rebuild`.
- قيود المادة 10 تُفحص في كل مراجعة: Next.js 14 · TypeScript · RTL · صور CDN المشروع فقط · لا أسعار · صفحات المدن تبقى كاملة.
- أي commit يكسر أحد الفحوص أعلاه يُبلَّغ صاحبه فوراً في ثريد المهمة ويُصلَح في نفس الدورة.
- التوقيع النهائي «صفر عيوب بصرية» مشترك: المصمم + مراجع الكود (المادة 7)، بأدلة لقطات قبل/بعد.
