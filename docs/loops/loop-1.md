# Loop 1 — خط الأساس والتحليل (مغلقة)

**الحالة:** مغلقة بقرار مدير المنتج

**الفرع:** `feat/homepage-rebuild`

**نقطة البداية:** `67e4024`

**قرار الإغلاق والعقد الرقمي:** `4b018c8`
**النطاق:** قياس بناء إنتاجي، زحف وأصول، وصولية وفحص بصري، تحليل داخلي وتنافسي، وتثبيت C1–C7 قبل التنفيذ.

> هذا سجل تجميعي. المصادر الأولية هي ملفات `docs/evidence/` و`docs/research/` المشار إليها أدناه.

## 1. النتيجة التنفيذية

- **البنية التقنية سليمة إجمالاً:** TypeScript بلا أخطاء، 48 صفحة HTML مزحوفة كلها 200، و161 صورة مستخدمة بلا كسر؛ زحف QA الأوسع اختبر 63 مساراً داخلياً كلها 200 و88 رابطاً خارجياً سليماً.
- **المشكلة مثبتة كبنية محتوى، لا كأعطال:** الرئيسية تعرض 5 أقسام فقط و126 وسم صورة، لكن لا تعرض خدمات أو معرض أعمال حقيقي في المتن؛ العناصر المحسوبة غالباً شعارات/أيقونات.
- **الأداء دون القبول على الموبايل:** القياس المرجعي Performance 79، LCP 4.1s، TBT 310ms. إعادة QA مستقلة سجلت 81، 4.0s، 290ms؛ الاختلاف طبيعي بين تشغيلين، وكلاهما يثبت فجوة Performance/LCP.
- **الوصولية:** الرئيسية 100، لكن `/contact` سجلت 97 بسبب التباين وعدم تطابق اسم label؛ كما رُصد 40 هدف لمس أصغر من 44px عند 360px.
- **البناء غير نظيف:** نجح build وTypeScript، لكن توجد 4 تحذيرات lint/build.
- **الفحص البصري:** RTL سليم وصفر overflow، لكن V1–V7 مثبتة؛ أبرزها إخفاء الأقسام حتى IntersectionObserver، غياب الأعمال الحقيقية، وطول 5559px على عرض 360 مع 5 أقسام فقط.
- **القرار:** ثُبّت العقد الرقمي C1–C7 في `docs/PLAN.md` وبدأت Loop 2.

## 6. أسباب الأداء الجذرية

- 74 طلباً و1.23MB transfer في قياس Lighthouse المرجعي.
- main thread نحو 7.2s؛ chunk 148 استهلك 4104ms.
- Script Evaluation = 1589ms؛ Style & Layout = 1032ms.
- نحو 145KB JavaScript قابل للتوفير، وأبرز مساهميه GTM/Ads.
- 12 ملف خط WOFF2 = 179KB؛ المطلوب الاقتصار على الأوجه الحرجة.
- صورة Hero تحتاج `next/image` priority وأبعاداً صريحة، بلا اعتماد على hydration لإظهار LCP.

## 7. مخاطر لا تُغلق في Loop 1

- 25 ثغرة npm audit: 8 high و17 moderate، دون critical؛ أغلبها أدوات تطوير، مع مخاطر متبقية في Next 14.2.x وقيد يمنع الترقية الكبرى.
- لا اختبارات آلية ولا CI؛ `REVIEW_GATE.md` هو الحاجز المؤقت.
- PAT ظهر في رسالة قناة؛ يلزم إلغاؤه خارج نطاق الكود، ولا يُعاد تخزينه في الوثائق.
- middleware وتحويلات WordPress وحماية صفحات المدن خطوط انحدار لا تُمس بلا دليل.
